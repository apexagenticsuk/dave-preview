Where do I get a key?

Your web person sets this up once with you. In short: sign in to github.com, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Pick Only select repositories → apexagenticsuk/dave-preview, and under Repository permissions set Contents to Read and write. Copy the key and paste it above. Your GitHub account also needs to be added to the website project by your web person.

How to use the editor

1. Sign in

Open this page and paste your editor key, then tap Sign in. You only do this once on each phone or computer. To sign out, tap Sign out at the top.

2. Change a date

Go to Shows. Tap the date and pick the new one, change the venue or town, and paste the ticket link (or a phone number for phone bookings). Tick Sold out when it sells out. + Add a show adds a new one; Delete removes one.

3. Swap the poster

Go to Poster, tap Choose a new banner and pick a photo from your phone. It is shrunk automatically.

4. Check it

Tap Preview to see the whole site with your changes before anyone else does.

5. Publish

Tap the big red Publish button. The real website updates in about a minute. If it doesn't, wait two minutes and refresh the page.

Made a mistake?

Tap Undo all changes before publishing. After publishing, just fix it and publish again. Every published version is kept, so your web person can always roll back.
